# Abo3reb PDF

قارئ PDF عربي لنظام Android بواجهة أنيقة ومشروع منظم قابل للتطوير.

## الميزات الحالية
- شاشة ترحيب باسم Abo3reb PDF.
- اختيار ملف PDF من الهاتف باستخدام منتقي الملفات الرسمي في Android.
- عرض الصفحات والتنقل بين السابقة والتالية.
- حفظ آخر الملفات المفتوحة وتذكّر آخر صفحة لكل ملف.
- مشاركة الملف مع التطبيقات المتاحة على الهاتف.
- لا يحتاج إلى صلاحية التخزين الشاملة أو اتصال بالإنترنت؛ يختار المستخدم الملف بنفسه.

## التقنية
- Kotlin وAndroid Views.
- PdfRenderer المدمج في Android لعرض الصفحات.
- minSdk 26 وcompileSdk/targetSdk 35.
- Gradle 8.10.2 وAndroid Gradle Plugin 8.8.2.
- GitHub Actions لبناء Debug APK تلقائيًا.

## البناء
افتح المستودع في Android Studio مع JDK 17 وAndroid SDK Platform 35. إذا أردت البناء من الطرفية، ثبّت Gradle 8.10.2 وAndroid SDK ثم نفّذ:

    gradle assembleDebug

سيظهر ملف APK في المسار app/build/outputs/apk/debug/app-debug.apk.

## الحصول على APK من GitHub
بعد الدفع إلى فرع main، افتح تبويب Actions في المستودع. افتح تشغيل Android CI الناجح ونزّل artifact باسم Abo3reb-PDF-debug-apk. ملف Debug APK مخصص للتجربة، وليس إصدارًا موقّعًا للنشر في المتجر.

## ملاحظات التطوير
هذه نسخة تأسيسية قابلة للتوسعة. يمكن إضافة البحث داخل النص، وإشارات مرجعية متعددة، والوضع الداكن، والتكبير المتقدم، والاختبارات قبل اعتماد إصدار إنتاجي.
